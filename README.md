# Битва игр 1990–2026

Тест в стиле picu.co: из двух игр выбираешь одну, пока не останется лучшая. В конце — таблица топа. Есть режим «вдвоём».

- `site/` — сам сайт (GitHub Pages): `index.html`, `games.json` (1577 игр), `specials.json` (особые сцены), `videos.json` (ID роликов).
- `scripts/fetch_videos.py` — ищет трейлеры на YouTube (yt-dlp) и проверяет, что их можно встроить.
- `.github/workflows/pages.yml` — при каждом пуше ищет недостающие ролики и публикует сайт.

Добавить игру: допиши `["Название", год]` в `site/games.json` и запушь — ролик найдётся сам.
